LINUX One-time setup required

On Linux the kernel protects HID devices. You need ~30 seconds to grant your user access to the M913. You only have to do this once.

  1. 1
    Download the installer script:
  2. 2
    Open a terminal and run:
    cd ~/Downloads && chmod +x install-m913-udev.sh && sudo ./install-m913-udev.sh
  3. 3
    Unplug and re-plug the M913 USB dongle. Required.
  4. 4
    Press the connect button below.
